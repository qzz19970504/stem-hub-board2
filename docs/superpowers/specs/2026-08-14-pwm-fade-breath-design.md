# PWM 渐变与呼吸测试设计

## 目标

在现有 25 kHz LED PWM 上增加非阻塞渐变、Gamma 2.2 视觉映射、渐变时间掉电保存和呼吸灯演示模式，同时保持 18V 关断的最高安全优先级。

## AT 行为

- `AT+PWM=<0..100>` 设置感知亮度目标，系统任务从当前亮度平滑移动到目标值。
- `AT+PWM_TIME=<0..10000>` 设置整段渐变时间，单位 ms、10 ms 精度，默认 500 ms；0 表示立即切换。配置写入 Flash，重启后恢复。
- `AT+BREATH_TEST=ON|OFF` 控制演示模式。开启前必须先开启 18V；开启后在 0% 与 100% 间往返。
- 呼吸期间 `AT+PWM` 返回 `+ERROR:BREATH_ACTIVE`，`AT+PWM_TIME` 可修改并从下一半周期生效。
- `AT+BREATH_TEST=OFF` 从当前位置渐变回进入呼吸前保存的目标亮度。
- `AT+18V=OFF` 随时有效，并立即终止呼吸、PWM 清零和关闭电源。
- 状态响应增加当前亮度、目标亮度、渐变时间和呼吸状态。

## 架构

- `app_pwm_fade` 是纯状态机，负责时间插值、Gamma 映射和呼吸相位，不依赖 HAL/RTOS。
- `app_settings_record` 负责带 magic、版本、序号和校验的纯 Flash 记录格式。
- `app_settings_storage` 使用 STM32 最后一页 Flash（`0x0800FC00`）轮换保存配置；链接脚本将固件区缩小为 63 KiB，防止覆盖配置页。
- `app_output` 持有唯一输出状态并串行化 AT 与 system task 的访问；system task 每 10 ms 调用一次非阻塞推进函数。

## 安全与测试

- 18V 关闭不等待渐变，始终立即输出 0%。
- Flash 数据无效或校验失败时使用 500 ms 默认值。
- 主机测试覆盖解析边界、插值中途改目标、升降渐变、Gamma 端点与单调性、呼吸互斥、配置记录校验。
- 实机验证串口响应、CCR 逐步变化、呼吸启停、18V 强制关断以及复位后渐变时间恢复。
